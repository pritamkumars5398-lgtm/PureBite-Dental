# Internationalization

Official Flutter l10n. Files:

- `lib/l10n/app_en.arb` (template)
- `lib/l10n/app_es.arb`
- `l10n.yaml` at app root
- `flutter: generate: true` in `pubspec.yaml`

## Rules

- Default locale: `en`. Also support `es`.
- Every user-visible string is an ARB key (`loginTitle`, `patientsEmpty`, …).
- Spanish runs ~20% longer — do not fix widths to English.
- Patient names and treatment names are **data**, not l10n. Do not ellipsis them without a tooltip.
- Access via `AppLocalizations.of(context)!`.
