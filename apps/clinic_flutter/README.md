# DentalPin Clinic Flutter

Offline-first staff app (phone, tablet, desktop) for the DentalPin FastAPI backend.

## Read first

All coding rules live in [`docs/README.md`](docs/README.md). Cursor rules: [`.cursor/rules/`](.cursor/rules/).

Do not hardcode spacing, icon sizes, text styles, or API URLs. Use `AppSpacing`, `AppIcons`, `AppText`, and `ApiConstants`.
